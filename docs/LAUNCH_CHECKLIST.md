# Launch checklist (tick every box before `CONFIRM_MAINNET=yes`)

## Ownership
- [ ] Signed transfer-of-rights document (`docs/legal/TRANSFER_OF_RIGHTS_DRAFT.md`, reviewed by a lawyer)
- [ ] Code is in the operator's own GitHub account
- [ ] All accounts in Part 1 of `docs/HANDOVER.md` are in the operator's name, with 2-factor authentication on
- [ ] No key, wallet or account of the previous owner is used anywhere

## Keys
- [ ] New `MASTER_KEY` generated by the operator and backed up offline in two places
- [ ] Owner/fee wallet recovery phrase stored offline (hardware wallet recommended)
- [ ] Deploy key removed from `.env` after deployment

## Rehearsal on Polygon Amoy (test network)
- [ ] Contracts deployed and verified on Amoy
- [ ] Mint → list → buy (second wallet) → unlock → seller locked out → withdraw: all worked
- [ ] AI assist works with the operator's own Anthropic key (or is intentionally off)
- [ ] Prompt metadata pinned with the operator's Pinata account

## Legal & tax (India)
- [ ] CA consulted on income tax (30% VDA, 1% TDS), GST and business structure
- [ ] Lawyer confirmed whether FIU-IND registration / KYC is required, and it is in place if so
- [ ] Terms of service and privacy policy reviewed and published; URL set in `OPERATOR_TERMS_URL`
- [ ] Contact address for support and takedown requests set in `OPERATOR_CONTACT`

## Security
- [ ] Smart-contract security review done, or a conscious decision recorded to launch small first
- [ ] Platform fee set (`PLATFORM_FEE_BPS`, max 500) and fee recipient is the operator's wallet

## Go-live
- [ ] Contracts deployed and verified on Polygon; `deployments/polygon.json` committed
- [ ] Render service from `render.polygon.yaml`, Starter plan, all secrets set
- [ ] Custom domain connected, HTTPS working
- [ ] `/api/config` shows `polygon`, chain 137, `testnet: false`
- [ ] One small real end-to-end purchase tested
